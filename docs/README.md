# Yijing Oracle — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning, doing and fixing are different needs, so they live on different pages. Only the kinds that have content are listed here.

**New here?** → [Getting started](getting-started.md) — from the install to your first saved reading.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](getting-started.md)** | Learning-oriented. Cast the coins, read the hexagram, save the reading as a note. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "No endpoint reachable, or no model", "Interpretation failed", "Reading saved as a new note instead". |
| **[Set up image generation](image-generation.md)** | Task-oriented. The Local Image Generator plugin as the source of the meditation image. |

The [README](https://github.com/johannes-kaindl/yijing-oracle/blob/main/README.md) covers what the plugin does, how to install it and every settings section.
